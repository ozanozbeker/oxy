# Triage labels

The skills name five triage roles. This table maps each role to its GitHub label.

| Role              | Label in this repo | Meaning                                                    |
| ----------------- | ------------------ | ---------------------------------------------------------- |
| `needs-triage`    | `needs-triage`     | A maintainer needs to evaluate the issue.                  |
| `needs-info`      | `needs-info`       | A maintainer needs more information from the reporter.     |
| `ready-for-agent` | `ready-for-agent`  | The issue is fully specified, so an AFK agent can take it. |
| `ready-for-human` | `ready-for-human`  | The issue needs a human to implement it.                   |
| `wontfix`         | `wontfix`          | No one will work on the issue.                             |

When a skill names a role, such as "apply the AFK-ready triage label", use that role's label string from this table.
